# How to edit the Save Fort Hill website

You don't need any technical knowledge or a GitHub account.

## Getting in

1. Look for an email invitation from **Pages CMS**. Click the link.
2. Bookmark **https://app.pagescms.org**. That's where you'll edit from now on.
3. Choose the **save-fh-site** project.

## What you can edit

| In the menu | What it changes |
|-------------|-----------------|
| **Site settings & announcement banner** | The black strip at the top of every page, the letter and "Join the fight" form links, the posters link, the contact email |
| **Upcoming events** | The events section on the home page. Delete events once they're over. |
| **Home page** | Slogan, key facts, and the main text |
| **FAQ page** | The questions and answers (the page is hidden on the site for now). |
| **Press coverage** | The news stories, shown as cards with a photo. Click **Add an entry** for a new one and drag it to the top. |
| **Press page** | The intro text and media contact |
| **Contact page** | The intro text |

## Saving

Click **Save**. The live website updates in about **one minute**. There's no separate "publish" step, so what you save is public.

Made a mistake? Fix it and save again. If something looks broken, tell a site maintainer: every change is recorded, so any change can be undone.

## Tips

- **Announcement banner:** Turn it on for the next event and keep it to one line. Turn it off when the event is over.
- **Banner photos** (FAQ, Press, Contact pages): Use landscape (wide) photos, at least 1600 pixels wide. Always fill in the **photo description**. It's read aloud to people using screen readers.
- **Links:** Always paste the full address, starting with `https://`.
- **Headings in the main text:** Use the heading button for section titles, not bold text. It keeps the page tidy and accessible.
